## Overview

Unverum manages mods for Guilty Gear Strive, Dragon Ball FighterZ, and other Arc System Works titles, handling PAC archive extraction, mod conflicts, and load-order management through a clean GUI.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Unverum** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **PAC Archive Support** | Extracts and repacks Arc System Works PAC mod archives |
| **Conflict Resolver** | Detects overlapping file edits and prompts for priority order |
| **Game Presets** | Auto-detects installed ASW titles and configures paths automatically |
| **One-Click Launch** | Launch the modded game directly from the Unverum interface |
